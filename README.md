# 2027届秋招情报站 🎯

面向**产品 / 运营方向**求职者的 2027 届秋季校园招聘信息聚合网页，重点覆盖**上海、深圳、香港**的机会。

## 覆盖范围

- **互联网大厂**：字节跳动、腾讯、阿里巴巴、美团、京东、拼多多、网易、快手、小红书、米哈游
- **世界500强外企**：宝洁、联合利华、欧莱雅、汇丰 HSBC
- **新能源车企**：比亚迪、蔚来、理想、小鹏、特斯拉、小米汽车

## 功能

- 📋 公司卡片：开启/截止时间、投递渠道、岗位需求、薪资范围、笔试面试流程
- 🗓️ 秋招时间线：2026年6月 - 12月各阶段节奏
- 📊 对比表格：所有公司关键信息一览
- ⏰ 投递窗口建议：黄金投递时机提醒
- 🏙️ 城市机会：上海 / 深圳 / 香港专项分析
- 🔍 按类别、城市筛选 + 公司搜索

## 技术栈

纯原生 HTML + CSS + JavaScript，零依赖。数据存放于 `data.json`，由 WorkBuddy 每日自动调研并更新推送。

## 数据更新

`data.json` 中的 `lastUpdated` 字段标记最后更新日期。数据每日自动更新，信息仅供参考，投递前请以各公司官方招聘网站为准。

## 本地运行

```bash
# 任意静态服务器即可，例如：
python -m http.server 8000
# 然后访问 http://localhost:8000
```
